# Nmap Reconnaissance Lab

## Overview
This repository documents my Day 3 hands-on cybersecurity learning exercise using Nmap.

## Objectives
- Discover TCP ports on an authorized lab target.
- Practice service and version detection.
- Attempt operating system detection.
- Record scan results and assess the limitations of the findings.

## Tools
- Kali Linux
- Nmap 7.95

## Techniques Practiced
- `-sV` — Service and version detection
- `-sC` — Default Nmap scripts
- `-O` — Operating system detection
- `-p` — Specify TCP ports
- `-oN` — Save normal-format scan output

## Findings
- Target responded to Nmap.
- TCP ports 1–1000 were reported closed.
- No open TCP ports were identified in the scanned range.
- Operating system identification was inconclusive.

## Conclusion
This exercise helped me practice reconnaissance, interpret scan output, and document findings accurately. The results cover only the specified scan scope and do not establish that the target is completely secure.
